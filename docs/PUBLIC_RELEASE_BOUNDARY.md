# Public Release Boundary

This candidate intentionally excludes:

- SerpApi API keys or other credentials;
- private Diamond OS repositories, databases, runtime ZIPs, or source manifests;
- private P1/P2/Family/RLDB data;
- internal DZN32 BBR/DRC proof packets and local machine paths;
- raw submission-account screenshots.

The candidate contains only the bounded hackathon product source, test fixture, local runner, tests, and public-safe documentation.
